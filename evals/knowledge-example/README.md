# Example knowledge (fictional)

A made-up knowledge folder that matches the three example tickets in `evals/tickets`. It exists to
show what real knowledge changes in the output, and is safe to send to any AI provider.

Nothing here describes the real ShipNest. Do not copy it into `knowledge/`.

```bash
# the same tickets, with and without it
npm run eval -- --no-knowledge
npm run eval -- --knowledge evals/knowledge-example
```
