# ShipNest glossary

**Order**: a purchase pulled in from a webstore. Order numbers are unique per webstore.
**Shipment**: what is sent for an order. One order can have several shipments, and a shipment has one or more packages.
**Package**: one physical parcel in a shipment, with weight and dimensions.
**Webstore / Marketplace**: a connected selling channel such as Amazon, eBay, Shopify, Walmart, Newegg, Newegg Business or Best Buy.
**Carrier / Courier**: FedEx, UPS or USPS. A shipping account holds the seller's credentials for one carrier.
**Rate / Rate shopping**: the price and service options a carrier returns for a shipment. Rate shopping compares them before choosing one.
**Label**: the shipping label for a package, in PDF or ZPL format (ZPL is for thermal printers).
**Void**: cancel a generated label so the charge can be returned.
**Reprint / Redownload**: print or download a label that already exists, without buying a new one.
**Packing slip**: the printed list of items that goes inside the parcel.
**Ready to Ship**: a paid order that is not shipped, not cancelled, not partly shipped, and does not need attention.
**Needs Attention**: a paid, unshipped order that has a problem to fix first, such as an invalid address, a PO Box, an order on hold or a risky order.
**Partially Shipped**: an order where some shipments have shipped and others have not.
**To Process**: shipped orders that have a tracking number but whose tracking status is still only Label Created, so the carrier has not scanned the parcel yet. A tenant setting can skip this step.
**Reprint**: the status of a shipped order where printing failed (a printing error is recorded on the shipment or package).
**Returned**: a shipment marked as a return that has shipped.
**Return shipment**: a label created to send a parcel back. Cloned or created from an existing shipment.
**Clone shipment**: copy an existing shipment into a new one.
**Ship From / Ship To**: the sender and recipient addresses of a shipment.
**Tracking status**: the carrier's state for a package: Label Created, Processed, Picked Up, In Transit, Delivered, Voided, Error or Unknown.
**Bulk ship / Bulk labels**: generating labels for many selected orders in one action, with a progress dialog.
**Label Scan**: the warehouse screen where a scanned barcode or tracking number is recorded. A repeat scan is a "Duplicate Scanning".
**Filter set**: a saved combination of shipment-list filters.
**Automation rule**: a tenant rule that changes orders automatically when they match conditions.
**Tenant**: one seller account. Data is isolated per tenant.
**PII vault**: the separate store for addresses and contact details.
**BTO (Build-to-Order)**: kit details attached to an order.
**Printwise**: the print-queue integration. A print job is queued, processing, submitted or failed.
**Toolbox**: the ShipNest desktop app that prints labels on Windows.
